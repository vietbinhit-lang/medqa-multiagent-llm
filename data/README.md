# Data

## Files

| File | Status | Purpose |
|---|---|---|
| `sample_dev.jsonl` | **Bundled, original** | 20 self-authored USMLE-style clinical vignette questions. Not from the official MedQA-USMLE benchmark. Lets the pipeline run end-to-end with zero downloads, for development and smoke-testing only. |
| `dev_150.jsonl` | Generated by `prepare_medqa.py` | A 150-question sample of the official MedQA-USMLE train/dev split, for prompt tuning and error analysis. Not for reported results. |
| `official_test.jsonl` | Generated by `prepare_medqa.py` | The full official MedQA-USMLE test split (1273 questions). Run each variant on this **exactly once** and report those numbers. |

## Schema

Every file is JSON Lines (one JSON object per line):

```json
{"id": "sample_001", "question": "...", "options": {"A": "...", "B": "...", "C": "...", "D": "..."}, "answer": "B"}
```

- `id`: unique string id.
- `question`: the full question stem (vignette + question).
- `options`: exactly the four keys `A`-`D`, mapped to answer-choice text.
- `answer`: the correct option key (`A`, `B`, `C`, or `D`).

## Getting the official dataset

The sandbox this repo was scaffolded in has restricted network egress and
could not reach Hugging Face, Google Drive, or the usual mirrors, so
`sample_dev.jsonl` above is a stand-in, not the real benchmark. To get the
official data, run this **with real internet access** (e.g. in Colab):

```bash
pip install datasets
python data/prepare_medqa.py --dev-size 150 --seed 42
```

This tries a couple of known Hugging Face mirrors of MedQA-USMLE-4-options
and writes `data/dev_150.jsonl` + `data/official_test.jsonl` in this
repo's schema. If neither mirror is reachable, download the official
archive released by the paper's authors and pass the extracted files with
`--local-train` / `--local-test` instead (see the script's `--help`).

Once generated, update `data.dev_path` / `data.test_path` in
`configs/*.yaml` to point at the real files instead of `sample_dev.jsonl`.
